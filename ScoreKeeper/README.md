# ScoreKeeper: Add functionality with Swift Testing

Continue refining the models in Score Keeper by creating a model that keeps track of the game state and resets players’ scores when the game starts. Write unit tests with Swift Testing as you build your app to ensure it works as intended.

## Overview

These resources are associated with the [Add functionality with Swift Testing
](https://developer.apple.com/tutorials/develop-in-swift/add-functionality-with-swift-testing) tutorial. This is part of the [Custom types and Swift Testing](https://developer.apple.com/tutorials/develop-in-swift/welcome-to-data-modeling) tutorials from [Develop in Swift](https://developer.apple.com/tutorials/develop-in-swift) by Apple.

## Using these resources

Follow the tutorial instructions in section one of [Add functionality with Swift Testing](https://developer.apple.com/tutorials/develop-in-swift/add-functionality-with-swift-testing) to use these resources within the Xcode app.
